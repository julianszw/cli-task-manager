# Main Menu (removido)

## Purpose
Esta capacidad fue eliminada. La aplicación ya no muestra un menú principal de opciones separado: la vista única de tareas (ver `interactive-cli`) es ahora la pantalla inicial sobre la que se ejecutan todas las acciones (crear, completar, reabrir, eliminar, purgar) y se alterna el tema.

## Requirements

_No aplica — capacidad eliminada y reemplazada por `interactive-cli`._
