# CLI Interface (removida)

## Purpose
Esta capacidad fue eliminada. La interacción por terminal de la variante CLI básica
(prompt de texto con comandos `add`, `list`, `complete`, `purge`, `help` y `exit`)
ya no existe: la única forma de interactuar con la aplicación es la vista única de
tareas (ver `interactive-cli`), sobre la que se ejecutan todas las acciones con
atajos de teclado.

## Requirements

_No aplica — capacidad eliminada y reemplazada por `interactive-cli`._
